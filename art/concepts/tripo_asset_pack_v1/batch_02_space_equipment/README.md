These 16 transparent PNG crops come from the user-selected 4×4 equipment sheet. Files are numbered in reading order: left to right, top to bottom. Each crop is one distinct object; use each as its own Tripo image-to-3D input. Do not upload the whole set as multi-view images of one object.

The Spore column identifies the closest **gameplay role**, not a claim that our designs or mechanics are copied one-for-one. Several concepts are original physical representations of abilities that Spore presented as ship tools or effects.

## Tripo handling

Each numbered PNG is already isolated and has transparent margins. Generate one model per file, export GLB, and place downloads directly in `assets/tripo_inbox/`. A Tripo multi-view submission means several views of the **same object**, so do not put different numbers into one multi-view job. Check the displayed batch limit and total credits before using any batch-generation control.
