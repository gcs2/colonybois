# Local Tripo staging folder

Put unreviewed Tripo `.glb` exports here with the matching concept stem, for example `arc-lance-module-v1.glb`. This folder is ignored for model binaries so rejected and experimental generations do not enter Git. Do not put credentials here.

After an asset passes the in-game review, copy the approved GLB into its final runtime folder (`assets/encounter/`, `assets/world/`, or `assets/city/`) and keep its concept, Tripo settings/task ID and import notes in the matching art record. Never use `art/tripo_ready/`.
